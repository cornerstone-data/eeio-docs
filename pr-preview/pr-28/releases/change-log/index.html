Summary

This table summarizes all the data and methodology changes behind Cornerstone EEIO 2026, compared to both USEEIO v1.4 and CEDA 2025.

Model reconciliation¶

The USEEIO and the US portion of CEDA had 18 methodological differences. Cornerstone EEIO adopted either one of the approaches for each difference or improved the approach. For more details on each topic, see our open discussions on GitHub.
