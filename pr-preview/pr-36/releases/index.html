Releases

Summary

Each Cornerstone EEIO release is a version of the model together with the data products published from it. For Cornerstone EEIO 2026, the primary data product is the set of spend-based GHG emission factors. This page lists each release, the data products it publishes, and its release note and change log. Download the data from Zenodo.

The model and its data products¶

The Cornerstone EEIO model is the multi-regional input-output model described in the IO model and the GHG extension. A data product is something published from the model for others to use. Cornerstone EEIO 2026 was developed to produce cradle-to-gate emission factors for the goods and services that organizations commonly buy, so the emission factors are its primary data product. How they are calculated from the model is described in Calculating the emission factors.
