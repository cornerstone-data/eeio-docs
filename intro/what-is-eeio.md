:::{tip} Summary
An environmentally-extended input-output ({term}EEIO) model combines data of how outputs produced by sectors in an economy serve as inputs for other sectors along with environmental attributes of each sector. When the economic data is extended with environmental data this way, such as with GHG emissions, the resulting model can produce emission factors that represent the GHG emissions across a whole supply chain per dollar spent on a sector's products.
:::

## Where EEIO comes from

EEIO grew out of economic input-output analysis when economist Wassily Leontief added the pollution generated by each sector to his model of the economy [@leontiefEnvironmentalRepercussionsEconomic1970], and it has been a basis for carbon footprinting of nations, organizations, and products over the last few decades [@minxInputOutputAnalysisCarbon2009].

## The parts of the model

Each data component is put into a matrix, named by a letter that is common in input-output analysis and used throughout these docs (see [](../reference/notation.md)). Input-output analysis then combines the matrices with matrix algebra.

- **Input-output tables.** The supply (`V`) and use (`U`) tables record which sectors produce which products, and which products each sector and final user buys. From them come the direct requirements (`A`), the inputs a sector buys per dollar of its output, and the total requirements (`L`, the Leontief inverse), which add up the purchases through every round of suppliers. See [](../io/index.md).
- **Environmental extension.** Emissions of each gas by each sector (`E`), divided by the sector's output, give the direct emission intensities (`B`). Characterization factors (`C`) convert each gas to CO₂-equivalent. See [](../ee/index.md).
- **Emission factors.** Combining the two gives the direct emission factors, `D = C × B`, for what a sector emits itself, and the total emission factors, `N = C × B × L`, for what is emitted across its whole supply chain.

## EEIO and life cycle assessment

An EEIO model has the same matrix structure as the models used for life cycle assessment (LCA) [@suhDevelopingSectoralEnvironmental2005]. In both, a matrix of the inputs each activity needs is inverted to trace every upstream supplier, and a matrix of emissions per unit of each activity is multiplied through it. The difference is that EEIO describes sectors in dollars, where LCA usually describes individual processes in physical units. Because of this shared structure, EEIO data can serve as background data in LCA, as discussed in {cite:t}`ingwersenConsideringInputoutputDerived2026`.

## Multi-regional models

A single-country model assumes imported products are made the same way, and with the same emissions, as products made at home. A multi-regional input-output ({term}`MRIO`) model instead links countries' input-output tables through international trade, so each import carries the supply chain and emissions as it was produced in the origin country. For the companies reporting to the Carbon Disclosure Project (CDP), in one study using an MRIO model instead of a U.S. single-region model raised their estimated upstream emissions by about 10% [@davisImportanceMultiregionalAccounting2025]. The Cornerstone model is an MRIO model; see [](../io/index.md#from-single-country-tables-to-the-multi-region-model).
