The Cornerstone EEIO follows an annual update cycle. Every year we release a version named after the release year, so Cornerstone 2027 will be released in 2027. Releases are publicly available every October so companies can plan accordingly. Each release builds on one time series of emission factors: Cornerstone EEIO 2026 publishes the 2017 to 2026 series, and Cornerstone EEIO 2027 only adds the 2027 emission factors to it, so results stay continuous from one year to the next.

The Cornerstone EEIO is developed in two parallel versions, each with its own release cycle (see {numref}`release-cycle`).

**Research version.** This version is updated continuously and has many releases. It is where new science is developed and tested.

**Corporate version.** This version is released every October with data updates, bug fixes and small improvements. Each annual release adds that year's emission factors to the existing time series. Its methods stay stable for five years, so companies can make plans, set targets and measure progress against a consistent model.

**Major updates.** Every five years, a major update brings the science proven in the research version into the corporate version and starts a new time series built with the updated methods. The following annual releases extend that series for five years. The first series, built with the 2026 methods, starts in 2017 and is extended through 2030, and the next major update is in 2031.
